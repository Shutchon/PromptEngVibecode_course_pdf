## 🎨 เกี่ยวกับสไลด์

- **ธีม Industrial Dark HMI** — พื้นหลังเข้มสไตล์หน้าจอควบคุมเครื่องจักร ใช้สีสัญญาณตามมาตรฐานความปลอดภัยหน้างาน (เขียว = ปกติ, เหลือง/แอมเบอร์ = เตือน, แดง = อันตราย/ข้อห้าม) ซึ่งเป็นเนื้อหาในตัวของวิชา
- **เนื้อหาภาษาไทย + ศัพท์เทคนิคภาษาอังกฤษ** (Prompt, LLM, Hallucination, spec.md, Lockout/Tagout ฯลฯ) เพื่อให้นักศึกษาคุ้นเคยศัพท์ที่ใช้จริงในเอกสารวิชาการและหน้างาน
- **ทุกสัปดาห์มีโครงสร้างเดียวกัน:** ปก → กฎเหล็ก Lab Survival Guide 4 ข้อ → บรรยาย → Workshop ปฏิบัติการ 2 ชม. → สิ่งที่ต้องส่ง + เกณฑ์ตรวจรับ
